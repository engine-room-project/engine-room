# Engine Room

Unpublished release candidate. The project licence and public release require owner decisions.
The candidate has automated evidence; it has not passed independent-account provider,
GPU, shutdown or billing acceptance. Do not treat it as a supported public release.

Engine Room is a Windows window for private remote model access through optional named
connections. A fresh installation has no provider, credentials or account configured.
Renting a disposable GPU and connecting to an existing model are separate actions.
Managed rentals require an independently hosted Linux controller; opening the window
never rents anything. Persistent storage can keep billing after compute stops.

Start with [installation](docs/INSTALLATION.md), [supported combinations](docs/SUPPORTED_COMBINATIONS.md),
